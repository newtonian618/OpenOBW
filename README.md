An Open Source Truck OWB (on-board weighing) System

OpenOBW是一个开源的车载称重系统项目。车载称重广泛应用在各种不同用途的卡车、工程车辆、起重机、挖掘机、装载机、起重机等机械上。欧洲、美国、澳大利亚等发达国家和地区车载称重系统的普及率已经相当高，其中知名的供应商有意大利的VEI，美国的VPG以及rightweight等公司。不过这些国外公司的产品动辄几千美元，对大多数国内用户来说难以负担。

本项目旨在提供一个完整的OBW系统解决方案，包括传感器、车载显示屏以及手机APP等，所有电路和代码全部开源，一辆卡车DIY安装下来仅需数百元，并且安装十分方便。

本项目遵循Apache 2.0开源协议。OpenOBW的设计在一些车辆上测试重复精度可以优于3%（前后各3个传感器配置，静态重复测量），并且已经被证明可以长期稳定运行。但具体使用情况依赖于具体开发者在此基础上的开发能力，良好的车况，优秀的数据处理算法及良好的安装工艺都会对精度和可用性产生巨大影响，在此我们不对DIYer进行任何可用性、精度以及可靠性保证。

OpenOBW采用的是一种被VEI、VPG等公司广泛采用的成熟技术，国内也有一些厂商采用。其原理是：弧形的板簧悬挂的卡车在受到载荷的压力时板簧会变平，板簧两端与地面所成角度会变小，并且载重越大板簧就会变得越平，两端与地面的角度就会越小。当卡车从空载变为满载时板簧两端与地面的角度变幅可达十度以上。利用这一关系，只要测量出板簧与地面夹角即可反算出车辆的载重。

电路：
随着半导体技术的发展，IMU（Inertial Measurement Unit）已经十分成熟，测量倾角变得十分简单，这正是本项目的技术基础。OpenOBW采用应用广泛的BMI088六轴IMU作为核心器件，用STM32F103C8T6对齐进行控制，并通过RS485芯片MS2548与主机进行通信。当然传感器还需要电源，考虑到卡车上的供电通畅是24V并且会有很大的波动，电源芯片选择了工作电压超过40V的GSM61410。电路图源文件请在Circuit目录获取。

结构：
OBW工况比较差，肯定需要一个比较牢固的结构，最稳妥的方法就是搞个盒子整个给封起来。外壳可以用3D打印，真正应用场景不要用PLA材料，用不了多久。建议用PETG-CF，用ASA-CF就更好了。设计图如下：
